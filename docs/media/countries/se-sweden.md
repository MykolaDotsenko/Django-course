# Sweden (SE) — Country Media Prompt Pack

Currency: `SEK`

Read [Country Media Production System](../00_COUNTRY_MEDIA_SYSTEM.md) before using these prompts. Every generation is assembled as:

`Global Premium Image Contract + role contract + country prompt body below`.

## Visual thesis

Stockholm should feel warm-minimal, digitally fluent and human: water, Nordic architecture, transit, café culture and soft natural light with less sterility than generic Scandinavian design imagery.

### Preferred local cues

- Stockholm waterfront/urban islands or clean street geometry
- subway/tram/ferry cues used naturally
- fika coffee/bakery context
- light timber, stone, muted textiles and brushed metal
- card/mobile payment as ordinary everyday interaction

### Avoid

- IKEA-like showroom shorthand
- blue-yellow flag palette
- Vikings, red cottages or wilderness as default
- empty hyper-minimal scenes with no local life

## P01 — Hero Wide

**Target:** `static/images/country-media/se/hero/se-hero-v01.webp`

Photograph Stockholm in soft overcast or long-evening light: layered waterfront architecture or an elegant street, subtle ferry/transit movement, a few unposed locals and muted reflections. Use pale stone, warm timber, deep green/blue-grey and charcoal. Preserve one visually quiet third for UI.

Composition: one coherent contemporary scene, not a collage. Keep the main visual interest away from at least one outer third so product UI can coexist with the crop. Preserve architectural lines and realistic scale. People, if present, should feel incidental and unposed.

## P02 — Everyday Value

**Target:** `static/images/country-media/se/everyday-value/se-everyday-value-v01.webp`

Create a refined fika moment: coffee and a cinnamon/cardamom bun or simple bakery item on a clean but lived-in café table with warm timber/stone and soft Stockholm window light. Keep it everyday, not styled as a food campaign.

Frame at table/counter/hand level rather than as a product advertisement. Do not print an invented price as a focal element. Any signage should be incidental and plausible, not AI-generated gibberish dominating the scene.

## P03 — Payment Culture

**Target:** `static/images/country-media/se/payment-culture/se-payment-culture-v01.webp`

Show a routine card or mobile payment in a contemporary Stockholm café, bakery or small retail environment. Keep the interaction subtle and technologically normal, with no bank/app branding and no implication of universal payment behavior.

Show the transaction naturally inside a real-feeling setting. Keep hands anatomically correct, device geometry plausible and the payment terminal/phone secondary to the human context. No visible bank/app logos unless they are incidental and accurate; preferably use neutral interfaces.

## P04 — Local Detail

**Target:** `static/images/country-media/se/local-detail/se-local-detail-v01.webp`

Create a tactile Stockholm detail using water reflection, transit geometry, timber, ceramic cup and brushed metal. Keep the composition soft, quiet and contemporary, with no flag-color styling.

Treat this as a premium editorial insert: tactile materials, quiet composition, a small number of meaningful local cues and excellent light. No souvenir arrangement, flag palette, postcard montage or overloaded prop styling.

## P05 — Desktop Interface Concept

**Target:** `docs/assets/country-interface-concepts/se/desktop/se-interface-desktop-v01.webp`

Create a 16:10 premium desktop design concept for Cultural Currency Converter focused on Sweden. Use the sample conversion **100 EUR → SEK**. Use warm ivory, charcoal, deep forest and a muted blue-grey/brass accent. The SEK result should dominate; pair it with one calm Stockholm image and generous Nordic spacing. The screen should communicate: source amount → destination amount → local context. Make the numeric result the largest element. Use only minimal readable text: “Cultural Currency”, country name, currency codes, amount and result. Integrate the P01 visual language as one restrained destination image area. Do not turn the interface into a travel booking site or analytics dashboard.

## P06 — Mobile Interface Concept

**Target:** `docs/assets/country-interface-concepts/se/mobile/se-interface-mobile-v01.webp`

Create a 9:16 premium mobile design concept for Cultural Currency Converter focused on Sweden, using **100 EUR → SEK**. Translate the desktop hierarchy into a believable single-column mobile flow: compact source/destination selector, large conversion result, one editorial country image, then concise local-value/payment context. Make the mobile concept warm-minimal rather than sterile: one strong SEK result, one Stockholm crop and a concise everyday-value strip. Keep tap targets believable, spacing generous and visible copy minimal. No tiny dashboard cards, fake phone chrome, floating glass panels or crowded widgets.
